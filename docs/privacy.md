# Bilibili 视频文稿助手隐私政策

生效日期：2026-10-09

“Bilibili 视频文稿助手”（以下简称“本扩展”）是一个非官方的浏览器扩展，与 Bilibili、上海哔哩哔哩科技有限公司及其关联方没有隶属、赞助或授权关系。本政策说明本扩展在用户访问 Bilibili 视频页面时如何处理信息。

## 本扩展处理的信息

- 本扩展读取当前 Bilibili 页面 URL 中的视频标识（BVID）和分 P 参数，以确定要显示的内容。
- 当用户点击“加载字幕”或切换字幕时，本扩展向 Bilibili 官方接口请求视频信息、分 P 信息和字幕列表，并读取返回的字幕正文。
- 视频信息和字幕列表请求使用浏览器当前的 Bilibili 会话凭据（例如 Cookie），以便接口按用户当前登录状态返回结果。凭据由浏览器发送给 Bilibili，本扩展不会读取、提取、保存或上传密码、Cookie 或其他登录凭据。
- 字幕正文请求发送到 Bilibili 返回的 HTTPS 字幕地址，不携带本扩展的登录凭据。
- 当用户主动点击“复制”时，本扩展会将当前显示的字幕文本写入系统剪贴板。本扩展不会读取剪贴板内容。

## 信息去向和保存

本扩展直接在 Bilibili 页面中运行，请求发送到 Bilibili 提供的接口和字幕地址。本扩展没有开发者自有的服务器，不会将视频信息、字幕、登录凭据或剪贴板内容发送给开发者。

字幕列表和正文只在当前页面标签页的内存中使用。本扩展不使用本地存储、云端账户或分析服务保存这些信息。Bilibili 及其网络服务对请求日志、Cookie 和数据的处理受其自身政策约束。

## 权限和页面访问

本扩展没有额外的扩展 API 权限，未申请全站访问权限。内容脚本仅在下列指定 Bilibili 页面运行，用于读取视频信息和显示字幕；浏览器可能提示本扩展可读取或修改这些页面中的数据：

- `https://www.bilibili.com/video/*`
- `https://www.bilibili.com/list/watchlater*`

## 儿童隐私

本扩展不是面向儿童设计的服务，也不会主动收集儿童的个人信息。

## 政策更新

如果本扩展的实际数据处理行为发生变化，我们会更新本页面的生效日期和内容。发布新版本前，商店披露和扩展实现应与本政策保持一致。
